## Descripción

FoodStore es una aplicación web desarrollada con **TypeScript**, enfocada en la gestión y visualización de productos de comida.

La aplicación permite:

- Visualizar productos
- Agregar productos al carrito
- Actualizar dinámicamente la cantidad de productos
- Persistir datos utilizando LocalStorage
- Separar funcionalidades de cliente y administración

El objetivo principal del proyecto fue aplicar conceptos fundamentales de desarrollo frontend utilizando TypeScript y manipulación del DOM.

---

## Funcionalidades

- Listado de productos
- Carrito de compras
- Persistencia del carrito con LocalStorage
